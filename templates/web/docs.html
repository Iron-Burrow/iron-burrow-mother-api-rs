Private Beta API

Build with the Mother API

The production API is deliberately small, versioned, and protected by issued bearer API keys.

Download OpenAPI JSON

Authentication

Protected Beta requests use Authorization: Bearer <api_key>. Keep API keys out of browser code, repositories, logs, and screenshots.

Current Beta routes

  • GET /health — public process liveness.
  • POST /v1/balances — latest or historical balance snapshot for one account.
  • POST /v1/balances/bulk — bounded balance snapshots for multiple accounts.
  • POST /v1/erc20-transfers/search — bounded ERC-20 transfer search when enabled.

Identifiers and errors

Use canonical network_slug values for supported networks. Requests use structured JSON errors such as unauthorized, capability_not_granted, and rate_limited.

The OpenAPI document is the machine-readable source for request bodies, response shapes, limits, and examples.
